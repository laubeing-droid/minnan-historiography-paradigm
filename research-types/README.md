# 按研究问题选模块

先使用 `project-template/` 的五个入口，再选真正需要的模块。每个模块都给出选配信息、小样例和检查问题；示例除明确标注来源的部分外，均为设计练习，不是已经执行的研究成果。

- [文献对勘](文献对勘.md)：版本、页位、异读与释读。
- [地方志与事件时间线](地方志与时间线.md)：记事时间、修纂时间和同源转引。
- [人口与历史空间](人口与空间.md)：分母、单位、口径、边界和有限复算。
- [文化实践与田野](文化实践与田野.md)：参与者、劳动、传承、展示与日常、知情同意。
- [人物关系与网络](人物关系与网络.md)：关系含义、支持证据和未知边。
- [语言接触与跨地域比较](语言与跨地域比较.md)：记录者、书写系统、语言层次和地方差异。

一个项目可以混用几个模块，但不必把所有字段塞进统一大表。方法之间的交接也要检查，尤其别让模型计算出来的相似关系直接成为历史事实。
