# 任务看板

小项目直接使用本页；已有 GitHub Issues / Projects 就在这里放唯一入口，不重复维护两套状态。此模板不会自动创建 GitHub 拖拽看板。

| 编号 | 想法或要求 | 具体交付 | 负责/检查 | 状态 | 完成依据 | 受影响文件 |
|---|---|---|---|---|---|---|
| 01 | [用户原意的简明复述] | [能打开检查的结果] | | 待做 | | |

状态可用：待做、进行中、待检查、已完成、受阻、取消。只有交付存在且完成依据可核，才标已完成。

每次修改先找对应任务，改完查受影响文件。比如结论变了，要回看摘要和图注；方法变了，要回看输入、脚本和运行记录；来源版本变了，要回看引用和已导出结果。不要仅把本页打勾。

没有持续运行或提醒安排，就不要写“会一直监控”。
