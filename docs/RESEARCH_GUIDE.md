# 一项闽南文史研究怎样开始，又怎样做完

先想清楚要解释什么，再决定用哪些材料和方法。不是先建数据库，最后再找一个题目配它。研究进行中，材料可能迫使我们改题目，也可能否定原先的判断。这些改变应当留下来，而不是等到写结论时才把过程修成一条直线。

## 从地方生活提出问题

闽南文史包括语言、信仰、文艺，也包括土地、劳动、生计、家庭、组织与跨地域联系。以唯物历史观提出问题，可以追问一种文化实践靠什么生产生活条件延续，谁提供劳动、资金与场所，谁获得解释和展示它的权利。它不是先写好“经济决定一切”，再挑材料填空。

关心闽南文化的衰亡，首先要说清谁不再从事什么活动，哪种传授、组织或谋生条件发生变化，何时何地发生。旅游可见度增加，不证明日常实践仍在延续；词频下降或人口份额变化，也不证明文化已经灭亡。延续、重组、复兴以及群体之间相反的变化，都应进入比较。研究可以锋利，但证据不能为立场让路。

农业、海洋贸易、人口、制度与交通的作用，需要分期分区判断。“农业为基础、海洋只是补充”可以作为作者需要检验的问题，不能预填为每个时代的答案。区域研究应追查它们怎样互相作用，而不是建立一条永远不变的因果链。

## 划范围时同时看时间和联系

主要考察地区、存在直接联系的地区、只是用来比较的地区，所需证据不同。祖籍或语言相近是线索，不自动证明存在持续往来。今天的行政边界、历史活动空间和语言分布也不能互相替代。

把事件发生、材料写成、刊印或数字化的时间分开。地名与边界要带适用时期；日期只能确定到某个区间，就保留区间。研究台湾、潮州或海外社会时，也要说明当地制度、教育和身份形成，不把共同语言当作共同经历。

## 先问材料怎样形成，再问模型怎样处理

一份族谱、地方志或公报，是谁为谁写的，选择了哪些人和事？后来怎样保存、散佚或重印？扫描有没有缺页，OCR 有没有漏行，搜索系统把哪些东西排在前面？这些过程共同决定我们今天看得见什么。

原貌、转写、释读和研究解释分开保存。两篇文字可能抄自同一来源，两个公报可能出自同次调查；不能按链接数量累加独立证据。哈希、目录和字段只是帮助回查，不承担史料批判的全部工作。

## 做一个能检查的小样例，再扩展

先选足以暴露困难的材料试做。处理一页文献，就检查页位、异读和疑难是否能交代；比较两期人口，就检查单位、定义、地域和分母；研究关系网络，就先说明一条“关系”究竟指什么。

方法按问题选。细读可以解释一段材料中的用语，统计可以检查分布，空间分析可以揭示地点关系，向量检索可以帮助找相近文本。相似文本不自动是同一事件，图上的聚类不自动是历史群体，计算相关也不自动是因果。

一次实践至少留下输入版本、做法、结果及错误。没有运行的程序写未运行；代码能执行只是一层检查，仍要回到材料和解释。具体表格可用[研究记录](../templates/研究记录.md)和[论证与复核](../templates/论证与复核.md)，无需复制不适用的栏目。

## 验收的是有限交付，不是历史真理

本轮可以交付一份忠实转写、一个有限统计比较或一篇明确标注证据与限度的解释。应分别说明内容核读、技术检查和独立复核到了哪里。人类外部同行评审、另一个 Agent 复查、同一个作者重读，都有作用，但不是同一件事。

解释贯穿材料选择、实践和复核。最后再检查每条主张是否超出支持材料，有没有反证或替代解释尚未处理。完成一项交付，不代表有关问题永远终结。

## 把经验带到下一项研究

把值得重复使用的做法提炼成[单位工法卡](../templates/单位工法卡.md)。它应说明在什么条件下有用、失败在哪里、新项目采用前须查什么。新项目记下采用的范式版本；本仓更新不会自动改变旧项目的规则。

[RSI 说明](RSI.md)负责这一环。它服务于具体研究目标，不用无限自改进代替把研究做完。
