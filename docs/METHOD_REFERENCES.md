# 方法参照与本次阅读范围

这些来源帮助我们提出问题和组织研究，不替某个具体结论背书。核查日期：2026年11月12日。公开摘要、介绍、局部章节与全文阅读分开说明。

## 区域历史与文化实践

- Hugh R. Clark, *Community, Trade, and Networks*（1991），[结论章公开摘要与目录](https://doi.org/10.1017/CBO9780511572654.007)。本次未读付费全章。摘要提示人口、聚落交通与商业化的关系，泉州转口贸易的重要性随时期变化；因此农业、贸易和制度的关系要分期研究，不能预设固定主次。
- Tan Chee-beng 编，*Southern Fujian: Reproduction of Traditions in Post-Mao China*（2006），[出版社简介](https://cup.columbia.edu/book/southern-fujian/9789629962333/)。本次仅核简介。宗族、信仰及女性经验等主题提示我们从不同参与者的日常实践理解传统的再生产，不为文化必然灭亡提供现成结论。
- Jean DeBernardi, *Linguistic Nationalism: The Case of Southern Min*（1991），[公开文本](https://www.sino-platonic.org/complete/spp025_taiwanese.html)。本次读引言、结论、注1和文白读讨论开头，未通读。槟城、台南、厦门的比较说明语言联系与社会经历须分别考察；不能把当年田野描述直接写成今天现状。

## 数字史料与时空信息

- [CHGIS 数据库说明](https://chgis.fas.harvard.edu/pages/database/)与[使用说明](https://chgis.fas.harvard.edu/pages/howto/)：核读目标、模型、地名边界变化和时间序列/切片说明。借鉴地点有效时间、前后承接与来源定位，不宣称它包含任何时代的完整乡村边界。
- [Ranke.2 数字史料批判课程](https://ranke2.uni.lu/u/archival-digital-turn/)：本次读引言和练习1，未完成全部练习；另核[DARIAH课程介绍](https://campus.dariah.eu/resources/external/from-the-archival-to-the-digital-turn-a-lesson-on-source-criticism)。原始形成、保存与数字化都会改变材料的可见性和意义，OCR与搜索是中介。
- [TEI P5 不确定性、精度与责任章节](https://www.tei-c.org/release/doc/tei-p5-doc/en/html/CE.html)：本次读总述与22.1开头。借鉴分别记录疑读、日期精度和判断责任，必要时用Markdown/CSV即可，不强制安装XML系统。

## 可复查研究与协作

- [The Turing Way：Research Compendia](https://book.the-turing-way.org/reproducible-research/compendia/)：材料、方法、输出和环境说明可以从简单文件夹开始，不必先建平台。
- [Programming Historian 编辑指南](https://programminghistorian.org/en/editor-guidelines)及[投稿仓](https://github.com/programminghistorian/ph-submissions)：借鉴明确目标、试做、外部评审、修订和检查的分工，不把其期刊审批流程强加给每项小研究，更不把多Agent默认当作外部同行。
- [Cookiecutter Data Science 的组织原则](https://cookiecutter-data-science.drivendata.org/opinions/)及[仓库说明](https://github.com/drivendataorg/cookiecutter-data-science/blob/master/README.md)：借鉴原始输入不覆盖、加工与结果分开、沿依赖回查。历史研究的新异本或重扫本仍要保留，不机械照搬单一raw版本策略。
- [FAIR 原则](https://www.gofair.foundation/fair-principles)：标识、元数据、来源、许可和访问条件有助于复用。FAIR不意味着必须公开全部材料，更不认证史实正确。
- Wilson 等（2017），[Good enough practices in scientific computing](https://doi.org/10.1371/journal.pcbi.1005510)，核官方正文，支持可维护的研究组织与记录方式。
- Marwick、Boettiger、Mullen（2018），*Packaging Data Analytical Work Reproducibly Using R (and Friends)*，72(1):80–88，[DOI](https://doi.org/10.1080/00031305.2017.1375986)、[作者公开稿](https://faculty.washington.edu/bmarwick/PDFs/Marwick-Boettiger-Mullen-2018-TAS-research-compendia.pdf)。本次核摘要与引言，其计算可复现目标不能替代历史解释正确性。
